# 拆對標機制、挖鉤子、靜音檢查（2026-11-25 加）

借鏡 social-media-skills/skills 的 viral-reverse-engineering、hook-writer、contrarian-and-opinion、short-form-video-script 四個 skill（MIT，github.com/social-media-skills/skills）。選配技巧，不由閘門驗；已覆蓋的不重複（結尾回扣讓重播接得上、一卡約 2 秒的視覺節奏、第一個字 ≤0.5 秒）。

1. **拆對標拆機制，不拆表面**（viral-reverse-engineering）：步 0b 的 REVERSE.md 判讀與 `refs/` 對標分析，逐層各寫一行——鉤子、情緒或分享驅動、留人結構、格式包裝、選題角度、分享觸發、發布因素（帳號體量、時機）。每層跑反事實「拿掉這個它還會爆嗎」分四級：DRIVER（拿掉就崩，通常 1–2 層）、SUPPORTING（有幫助非主因）、INCIDENTAL（別抄）、CONFOUND（帳號大、一次性時事、運氣，不算內容教訓）。輸出一句機制（例：「反直覺鉤子＋同溫層認同感帶分享，配樂與題材是雜訊」）。一支爆款是假設不是定律：跨多支重複出現的機制才進帳本；主因是 CONFOUND 就直接寫不可複製，不編假公式。借的是機制不是台詞（SKILL.md 硬規則 7「借結構不照抄」照舊）。
2. **鉤子從內容挖，不貼上去**（hook-writer）：從稿子最強的原料挖（最反常識的事實、最高的代價、最違和的對比），不先想一個鉤子叫內容配合。候選鉤子要跨不同機制寫：好奇缺口、反直覺、代價、具體數字、點名身份、故事中段進場、錯誤教訓、前後對比、提問。Truth 與 Pull 是淘汰線：內容兌現不了的直接刪（贏點擊輸信任）、陌生人讀完不想要下一秒的不算鉤子。刪除項：暖場（「今天來聊」）、問候、描述畫面已有的東西、空泛預告（「你絕對想不到」）、自己回答自己的問題。
3. **靜音檢查**（short-form-video-script）：約八成短影音是關聲看的。稿寫完遮住旁白只看卡上字＋畫面動作，看不懂就改卡字，不靠配音補。前三秒三軌同鉤：畫面動作、卡上大字、第一句口白丟同一個鉤，不各講各的。
4. **角度過窄門測試**（contrarian-and-opinion 的 STAND 改寫成無立場版）：TREATMENT 定角度時自問「三個同類帳號會不會做這個角度？」會＝通識，再挖一層。攻迷思與慣性（idea）不攻人。片子不替論點背書（SKILL.md 硬規則 6 禁防衛性中立照舊）：steelman 在這個格式就是開場先承認觀眾的直覺（「你會不會覺得…」，先承認再轉）再用數據翻——是帶資訊的承認，不是沒資訊的自我辯護。
