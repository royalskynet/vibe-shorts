# 公開發布：揭露、出處、浮水印

每支片發布前都要過這一份。檢查寫成腳本了，見 `scripts/precheck.py`。

---

## AI 揭露：YouTube 不用勾，Meta 要寫一句

兩邊規則不一樣，理由也不一樣。

### YouTube：那題誠實答「否」

YouTube 的規則只管**寫實內容**，定義是「觀眾容易誤認為真實的人、地點、場景或事件」。豁免清單明確包含動畫、明顯不寫實的內容、特效，以及用生成式 AI 輔助製作。

我們的片是 canvas 畫出來的網點和排版，沒有一格會被誤認成實拍。所以上傳後那題「是否包含經改造或合成的寫實內容」答否。

旁白那邊也不在範圍內。YouTube 自己的例子寫「複製自己的聲音做旁白或配音」不需揭露，「複製別人的聲音」才需要。我們的音色是 VoiceDesign 生成的，沒有對應任何真人，連要複製的對象都沒有。

揭露不影響營利，所以不是「怕被降流量才不勾」。是這一題的正確答案就是否。刻意勾錯會讓系統對內容做錯誤分類。

### Meta：說明文字要寫一句

Meta 2024 的基準線寫的是「寫實影片**或聽起來像真的音訊**，經數位創造或改造」要用揭露工具。

我們的畫面不寫實，但旁白是聽起來像真人的合成語音。這一條我們可能落在範圍內，而且我沒找到 Meta 把動畫豁免寫進去。所以在 IG 和 Threads 的說明文字裡寫一句，成本是一行字。

IG 2026-08-31 那個新的「AI-generated profile」標籤不適用。它針對的是帳號裡出現 AI 生成的**人物**，沒標的會被限制觸及。我們片裡沒有人物。

### 標準揭露句（三平台都放，YouTube 只放描述欄不勾那題）

```
畫面由程式即時渲染，旁白為合成語音（非真人錄製，亦未複製任何人的聲音）。配樂為本片自行生成。
```

## 浮水印：不要燒

**被平台壓低觸及的是別的平台的浮水印，不是重複發布這件事。** 多個來源一致：把浮水印去掉，懲罰就消失。我們自己渲染母帶，本來就沒有任何平台的 logo，這一關天生就過。

自己的帳號名燒在角落是品牌選擇。我沒找到任何證據顯示它能提升觸及，所以不做，等有理由再加。

真正會吃掉觸及的是另外三件，兩件我們已經天生避開：

- **說明文字每個平台要不一樣。** 多個來源說複製貼上同一段會壓低互動。這一件要做。
- **不要用平台內建曲庫的音樂。** 那種授權不能跨平台，IG 的曲子發到別處會被消音。我們的配樂是 `mix.py` 自己生成的，天生避開。
- **錯開 30 到 90 分鐘發。** 只有一個來源這樣說，沒有其他來源佐證，證據弱。照做沒成本，但不要當成有根據的規則。

## 出處與授權

| 項目 | 狀態 |
|---|---|
| 事實內容 | 要在說明文字列來源。費馬那支還沒補 |
| 字體 | 系統字體渲染成點陣影片，輸出不含字體檔，不是字體再散布。B612 和 Architects Daughter 是 OFL |
| 配樂 | `mix.py` 自行生成，無第三方授權 |
| 聲音 | VoiceDesign 生成的音色，不對應任何真人 |

## 公開網址衛生

IG 和 Threads 發片時 Meta 會自己來下載影片，所以 mp4 一定要先放在公開網址上。那段時間要守三條。

1. **路徑用隨機字串，不要用片名。** 用 `flt-11days.mp4` 這種檔名，別人猜得到，也能順著猜其他檔案。每次發布產一個隨機 token 當目錄名。
2. **只開那一支檔案。** 不要把整個資料夾或整個埠攤出去。
3. **發完就關。** Funnel 開著的時候，那支檔案對整個網際網路可見，不只 Meta。

這三條寫進 `scripts/precheck.py`，檔名不是隨機 token 就不給發。
