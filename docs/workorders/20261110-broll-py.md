## 驗收

```bash
cd REPO_ROOT
python3 tests/test_broll.py
rm -rf /tmp/broll-acc
REPO_ROOT/.venv/bin/python scripts/broll.py fetch REPO_ROOT/tests/fixtures/reverse-2shot.mp4 --out /tmp/broll-acc --secs 2 --fps 30 --license CC0 --credit fixture
test "$(ls /tmp/broll-acc/*.jpg | wc -l | tr -d ' ')" = 60
python3 -c "import json;c=json.load(open('/tmp/broll-acc/clip.json'));assert c['count']==60 and c['fps']==30 and (c['w'],c['h'])==(1080,1920),c"
REPO_ROOT/.venv/bin/python -c "from PIL import Image;assert Image.open('/tmp/broll-acc/0001.jpg').size==(1080,1920)"
env -u PEXELS_API_KEY REPO_ROOT/.venv/bin/python scripts/broll.py search taipei --limit 5 --json > /tmp/broll-s.json
python3 -c "import json;r=json.load(open('/tmp/broll-s.json'));assert r,r;assert all(x['source']=='commons' and not any(b in x['license'] for b in ('SA','NC','ND')) for x in r),r"
rc=0; env -u PEXELS_API_KEY REPO_ROOT/.venv/bin/python scripts/broll.py search taipei --pexels >/dev/null 2>&1 || rc=$?; test "$rc" -eq 2
```

預期：全部 exit 0；抽出 60 張 1080×1920 jpg；Commons 搜尋有結果且無 SA／NC／ND；明指 Pexels 但沒 key 回 2。
