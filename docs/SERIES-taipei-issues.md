# 台北議題科普系列（行人地獄的格式）

使用者 10-29 定：照 `films/pedestrian-hell` 定稿（`34ae24b`）的寫法，把台北兩大陣營都有提出主張的其他議題各做一支。每支是單純的議題科普，不是選舉片。

## 稿子順序（照順序講，不跳回；10-30 起照 docs/WRITING.md §7 第 7–9 條）

範本稿＝`films/taipei-rent/narration.md`、`films/taipei-childcare/narration.md`（定稿 `bccd752`）。

1. 鉤子：台北市民的痛點問句＋一句答案＋一個數字。
2. 機制：為什麼會這樣，2–3 個原因，每個配數字。
3. 轉折：一個國際城市怎麼解，結果用數字講；接「回到台北，有兩種主張」。
4. 「第一種，…」：蔣陣營（含現任市府已推動的措施）。做法＋代價（錢／人／時間擇一講清楚）。
5. 「第二種，…」：沈陣營。做法＋代價。**跟上一段句數相同。**
6. 落點：回扣鉤子。
7. 提問：問觀眾自己生活裡的經驗。
8. 收尾：「<這件事>，跟每個人都有關。一起多關心，讓台灣更好。」

不寫懶人包；不寫「應該」「都能」。

## 不准

- 片內出現人名、政黨、「候選人」「選舉」「政見」「市長」「藍」「綠」。出處人名只寫在 SOURCES.md。
- 評哪一派比較好；台灣兩段回頭對照國際案例。
- 「死」字：改「失去生命」「救不回來」。
- 防衛性中立句（repo CLAUDE.md）。

## 來源

- 兩派主張：公視、央廣、中央社、自由、聯合等新聞報導，或台北市府官網新聞稿，或候選人本人頁面。每句在 SOURCES.md 附原文摘錄。
- 數字一定要對到原文；對不到就換數字，SOURCES.md 寫明對到哪一頁。
- 議題清單起點：blindvote.app/taipei 列出兩位都有提出的 8 個議題（托育、長照與高齡、公車與大眾運輸、校園教育、公園與運動、行人與交通安全、居住、防災治水），只拿來找題，主張內容回到新聞或本人來源。
