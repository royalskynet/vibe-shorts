## 第二部（約 1500–2400 字，段落參考，可調）

1. `## 第二部｜西景鎮的真相`：劇透提醒；艾格妮絲是阿嘉莎·哈克尼斯，活了幾百年的女巫；一六九三年在塞勒姆，女巫團因為她偷練禁忌魔法要處決她，她反過來吸光所有人的魔力；她被西景鎮的魔法吸引，想搞懂汪達怎麼辦到的。
2. `## 雙胞胎與緋紅女巫`：汪達在劇中「懷孕」，生下雙胞胎比利（能聽見別人心聲、會魔法）和湯米（超速，像舅舅皮特羅）；阿嘉莎揭穿汪達是「緋紅女巫」，天生的混沌魔法使用者；回收第一部「渾身緋紅光芒的女人」伏筆。
3. `## 告別西景鎮`：天劍局用幻視原本的身體重建出白色的幻視；西景鎮的幻視把記憶還給他，白幻視飛走、下落不明；汪達打敗阿嘉莎，把她困在「鄰居艾格妮絲」的身分裡；汪達放開小鎮，幻視和雙胞胎一起消失；她帶著《黑暗神書》躲起來研究。
4. `## 奇異博士2`：汪達被《黑暗神書》侵蝕，想闖進孩子還活著的其他宇宙；最後在萬達戈山摧毀所有神書，神殿崩塌壓在她身上，生死不明。
5. `## 阿嘉莎開播前`：阿嘉莎還困在西景鎮當艾格妮絲，直到一個少年解開咒語，要她帶路走「女巫之路」。第二部停在這裡。

## 第三部（約 1700–2800 字，段落參考，可調）

1. `## 第三部｜阿嘉莎的結局`：劇透提醒；少年就是比利，汪達放開西景鎮那一刻，他的靈魂進了一個車禍將死的少年威廉·卡普蘭的身體；女巫之路原本是阿嘉莎為了紀念兒子編的歌與騙局；同行女巫莉莉亞、珍妮佛、艾莉絲，還有阿嘉莎的舊情人瑞歐，真身是死神；阿嘉莎最後死去，變成鬼魂，陪比利去找下落不明的弟弟湯米。
2. `## 幻視去了哪`：第二部飛走的白幻視；《幻視任務》官方簡介：重啟後的幻視躲起來，逃避想把他變成武器的人；他在愛丁堡一間老酒吧打工，那是他和汪達以前常去的地方（回扣第一部的愛丁堡）。
3. `## 幻視腦中的宅邸`：幻視意識裡有一個心靈空間，東尼留下的 AI 都以真人模樣住在裡面，各一到三句：
   - 賈維斯：東尼的第一個 AI，從《鋼鐵人》當管家；名字來自霍華·史塔克的管家艾德溫·賈維斯；幻視的意識來源，在宅邸裡像大哥。
   - 星期五：賈維斯之後接手盔甲，陪東尼到終局之戰；化身來自帶大東尼的祕書艾莉森·霍根。
   - 伊迪絲：《蜘蛛人：離家日》東尼留給彼得·帕克的眼鏡，控制全球無人機防禦網。
   - 笨笨和 U：東尼工作室的兩隻機械手臂；《鋼鐵人》裡是笨笨把方舟反應爐遞給快死的東尼。
   - 奧創：被關在宅邸閣樓，能上網、每天畫畫。
4. `## 湯米`：官方簡介：一筆高額賞金逼幻視逃亡，同行的少年湯瑪斯·雪帕德，可能是他轉世的兒子；回扣第三部第一段比利在找湯米。
5. `## 收尾`：觀看順序《汪達幻視》→《阿嘉莎》→《幻視任務》；回扣「事物的美，不在於它能存在多久」；最後一行「現在，你可以開播了。」
