# 皮克敏「中國台灣」風波短片（films/pikmin-bloom）

## 定位

使用者貼來的一篇網路貼文當「引」：只借題材與事實線索，不借句子、段落順序、論證結構與立場措辭。貼文原文存 `refs/viral-text/pikmin-seed.md`（已被 .gitignore 忽略），只供相似度比對，不進稿。

## 進度（2026-11-19）

- WO-1a 建片目錄、WO-1b 事實查證＋爆款帳：o 完成，主 session 重跑驗收並 curl 核對 F1–F5 網址與證據內文，通過。
- 卡關：同題爆款 0 筆 ≥10 萬，`precheck.py` 爆款證據門過不了，待使用者裁決。
- WO-2 相似度閘改成逐句取最大相似度（沿用 precheck「台詞非照抄」算法），並加負控制：塞一句 SEED 原句進稿，驗收必須失敗。

## 分工

主 session 只寫工單、跑 `dcq`、驗收、把稿貼給使用者核；實作全派 o（`DCQ_ORDER=default`）。含稿子創作那張單不含憑證與個資，可送外部。

| 單 | 內容 | 驗收 | 人點頭 |
|---|---|---|---|
| WO-1 | 建片目錄＋爆款證據＋事實查證 | 檔案齊、`TREATMENT.md` 有爆款證據行、`meta/facts.md` 每筆有 URL 與判定 | 否 |
| WO-2 | 稿子草案（`narration.md`、`SOURCES.md`、三份 caption、`index.html` 的 `FACTS`） | 結構檢查＋對 SEED 相似度 < 0.4 | **是：稿全文貼出，說通過才跑 `approve.py`** |
| WO-3 | `humanize` → 反方稽核 → 稿冷讀 → 建置 → 目視自評 → precheck | `precheck.py` exit 0 | 否（建置不併發，一次一支） |
| 發布 | `deliver.sh`、YT／IG／Threads | `meta/published.json` | **是** |

## 兩段

**根治（內容正確）**
- 只用查得到的事實。使用者貼文裡「台灣占全球消費約 52%」「官方尚未正式說明」需找到原始來源與日期；找不到就標「未查證」，稿不用。
- 貼文的個人經驗（補習班推銷電話）與「GPS 個資外洩」推論沒有可驗證來源，稿不用。
- 稿禁防衛性中立語言（硬規則 6）；限定範圍寫進事實（日期、平台、對象）。

**預防加固（不再出錯）**
- 數字全進 `index.html` 頂端 `FACTS`，每個 key 對應 `meta/facts.md` 一行來源。
- WO-2 驗收加相似度閘：稿對 SEED 的 `difflib` 比值 < 0.4；對爆款逐字稿 < 0.6（硬規則 7）。
- 事件仍在演進，建置前再核一次「官方是否已發聲明」，facts.md 記查證日期。

## 風險

- 政治敏感題材，平台可能限流：不是寫稿閘的事，發布前人看一次。
- 免費模型查證可能抓不到網頁：工單要求它貼原始輸出，查不到寫「未查證」，不准編。
