# 任務

只讀下面「旁白稿」全文，照下面的 1–6 依序寫，不要查任何檔案、不要上網、不要補推作者意圖。

1. **你看懂的內容**（3 句內）：用你自己的話說這支片講了什麼。
2. **一句話主旨**：如果你說不出來，就只寫「說不出」。
3. **前 3 秒**（第一段）：會不會讓人停下來滑？理由。
4. **逐句追問**：哪一句看不懂、哪個轉折沒有理由、哪個數字沒說清楚是什麼。
5. **問題清單**：每條一行，格式固定 `- [硬傷|小問題] 第N句：問題 → 建議改法`；沒把握的寫「可能」。
   第 N 句從第一段第一句起算、全文連續編號。硬傷＝不懂或會被誤解而影響可信度；其餘算小問題。
6. 最後一行只寫 `VERDICT: 通過` 或 `VERDICT: 不通過`。
