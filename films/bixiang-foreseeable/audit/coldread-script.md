## 1. 你看懂的內容

這支片質疑幣想案的法院解讀：負責人禁止合作被當成作勢，沒有明講禁止又被當成默許。影片認為法院用「你應該知道」補足證據，讓負責人無論怎麼做都可能有罪。最後以岳飛的「莫須有」類比，進一步指控判刑與惹錯人有關。

## 2. 一句話主旨

幣想案的法院把禁止與沉默都解讀成有罪，因此影片質疑這是一場先定罪、再找理由的審判。

## 3. 前 3 秒

會讓我停一下。「拍桌禁止合作，卻被讀成有罪」有明確衝突，會想知道法院怎麼解釋。

但第二句立刻把它概括成「做什麼都有罪」，全文後面需要證明這個概括成立。稿內的「搜索之後」與「直接故意」證詞，反而讓我懷疑還有其他判斷理由。

## 4. 逐句追問

以下依正文編號，標題與小標不計。

- 第1、6句：法院認為可疑的是「拍桌禁止」，還是「搜索之後才採取措施」？這兩件事差很多。
- 第2、7句：「沒有明講禁止接盤口」和「沒有禁止跟詐團合作」是同一件事嗎？「盤口」是什麼？
- 第4句：被禁止的是所有加盟制度，還是這類業務採用加盟？「這是不對的」指公司違規，還是法規不合理？
- 第5、7句：既然曾強烈禁止，為什麼證人又說沒明講禁止？時間、對象或禁止事項有何不同？
- 第6句：兩家店與兩個店長有什麼關係？為什麼關店、換人？發生在搜索前還是搜索後？
- 第8句：「知情」是知道加盟主有幫派背景，還是知道加盟主與詐團合作？
- 第10句：中間商做的是什麼交易？「客人被騙才來」如何回應公司是否參與合作？
- 第11、12句：稿子承認有證詞，也說法院採信。為什麼後面會變成「證據不夠」甚至「不需要證據」？
- 第12句：審查什麼？提前交付題目如何協助詐團？影片認為這份證詞有什麼問題？
- 第13至15句：一審最後採用哪條認定路徑？兩條都用，還是分別適用不同被告或行為？
- 第16句：前面明明提到「預見」與「容任」，為何這裡變成「不管知不知情」？
- 第18至22句：岳飛故事如何證明本案證詞不可信，或法院沒有足夠證據？
- 第23句：前面哪一段支持「惹錯人」才被判有罪？阿扁、阿北在這裡各自代表什麼？

## 5. 問題清單

- [硬傷] 第1句：把「禁止合作」直接寫成有罪心態，與第6句的搜索後時點存在落差 → 說清楚法院質疑的是禁止行為本身，還是採取措施的時機。
- [硬傷] 第2句：把不同情境概括成禁止與不禁止都會有罪，稿內尚未證明 → 先交代兩項認定的時間、對象及理由，再提出質疑。
- [硬傷] 第4句：「加盟制度本身，法規明確禁止」範圍不明，「這是不對的」指涉也不明 → 明寫哪類業務的哪種加盟安排遭禁止，以及誰的行為不對。
- [硬傷] 第5句：禁止與第7句的未禁止表面矛盾 → 補上兩者的時間或禁止事項差異。
- [小問題] 第6句：兩家店、兩個店長的對應關係與處置原因不清楚 → 補充關店、換人的原因及時間。
- [硬傷] 第7句：「接盤口」沒有解釋，無法判斷與詐團合作是否同義 → 用一般觀眾能懂的交易行為取代術語。
- [硬傷] 第8句：「毫不知情」的知情對象不明 → 明寫法院認為負責人知道哪件事，以及如何從在場簽約推到該結論。
- [小問題] 第10句：「中間商」與「被騙才來」沒有說明被告如何回應合作指控 → 具體交代門市的交易角色，以及被告否認參與哪個環節。

- [硬傷] 第12句：「審查題目」用途不明，也缺少質疑證詞的理由 → 解釋題目如何被使用，並交代這份證詞哪裡有問題。
- [硬傷] 第13句：兩條認定路徑與實際判決結果沒有接起來 → 交代法院最後依哪條路徑認定哪些行為。
- [小問題] 第14句：「也算」省略了算什麼 → 明寫是認定何種故意，或構成何種犯罪。
- [硬傷] 第16句：「不管知不知情」與前文的預見、容任條件不一致 → 保留前述條件，具體質疑法院如何認定知情。
