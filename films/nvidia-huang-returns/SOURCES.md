# nvidia-huang-returns 事實包（2026-11-24 查）

主題：黃仁勳 2026-11-23 回任輝達執行長，為什麼市場與董事會等不了。旁白每句對應一筆下列事實。EP2 背景事實沿用 `films/nvidia-founder-return/SOURCES.md`（F 編號那邊的不重複列）。

- F2 全票回任：輝達 2026-11-23 新聞稿，董事會全票（unanimously）通過回任黃仁勳為總裁、執行長與董事，即日生效；董事會說與黃仁勳多次討論後對其坦率與領導能力滿意，並收到美國政府高層意見，「確信他的回任不構成國安風險」。黃仁勳聲明：「感謝給我第二次機會」。旁白寫「全票通過」「馬上生效」「美國政府高層跟董事會說，他回來不構成國安風險」。來源：NVIDIA 新聞稿 2026-11-23 https://nvidianews.nvidia.com/news/nvidia-board-reinstates-jensen-huang-as-president-ceo-and-board-director
- F3 市值：回任消息後輝達市值單日多了將近一兆美元（BBC：climbs by almost $1tn），科技股齊漲；台灣媒體報導盤前漲逾 30%、收盤漲約 33%。旁白寫「市值多了將近一兆美元」。來源：BBC https://www.bbc.com/news/articles/cq62pn6j42jko ；星島頭條（股價急升 33%）https://youtu.be/uVe6Ffb7Xx0
