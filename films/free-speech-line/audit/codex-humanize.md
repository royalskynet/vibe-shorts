## 逐句修改

- 你有沒有想過，罵總統還能上廣播是為什麼？ → 羅大佑怎麼能上節目罵總統？｜刪套語，點名事件，縮短鉤子。
- 羅大佑在專訪裡，直指總統與行政院長狼狽為奸。 → 他在廣播專訪裡，罵總統跟行政院長「狼狽為奸」。｜「直指」「與」改成口語，保留媒體轉述用詞。
- 隔天梁文傑回他，沒言論自由他根本上不了節目。 → 梁文傑回他，台灣沒言論自由，他怎麼上得了節目？｜刪未查證的「隔天」，用間接轉述。
- 搞懂這條界線，你才知道自己有多少空間。 → 你批評政府，法律管到哪裡？｜空泛利益承諾改成具體疑問。
- 答案在三條法律裡，方向其實都一樣。 → 反滲透法先看誰在背後叫你做。｜刪導覽句與「其實」，先講機制。
- 刑法一百條只罰動手的人，可罰的只有強暴跟脅迫。 → 刑法一百條把強暴、脅迫寫進要件，也處罰預備犯。／單憑批評政府，還不符合這些要件。｜原句漏掉預備犯，也把脅迫縮成動手；改用法定要件。
- 一九九二年修法，把陰謀犯整條刪掉。 → 刪除。｜沿革支線分散注意，「整條刪掉」容易被聽成整條刑法刪掉。
- 理由是陰謀犯對國家法益，還沒有明顯而立即的危害。 → 刪除。｜刪修法理由支線與抽象法律用語。
- 釋字六四四號擋的是事前審查。 → 那自己主張共產主義，政府能擋你成立團體嗎？／釋字六四四號就處理過這件事。｜改成具體情境，作中段再鉤。
- 政府不能拿政治主張，當成不讓你設團體的理由。 → 大法官認定，不能拿這個政治主張，當成不准成立團體的理由。｜「這個」承接共產主義主張，限縮原句泛稱。
- 理由書說，那等於讓主管機關審查言論本身。 → 刪除。｜重複前句機制，「主管機關」也偏書面。
- 反滲透法抓的是對價關係。 → 法條寫的是，受「滲透來源」指示、委託或資助。｜「對價」容易讓人以為一定要收錢，改回法定關係。
- 第三到第七條，都要先有指示、委託或資助才算數。 → 滲透來源包括境外敵對勢力的政府，還有它控制的組織。／有這層關係，還要看你做了什麼。／例如受這些來源委託，去做法條規定的遊說，就會受罰。／所以，同樣是表達意見，也要看有沒有受人委託。｜補回來源與行為要件，以事實第 10、11 條的遊說為例，避免把所有委託都寫成違法。
- 不過法律寫得漂亮，還是要看它實際怎麼跑。 → 刪除。｜無證據評語，也另開執法成效論點。
- 反滲透法上路五年，檢方起訴一百二十七人。 → 刪除。｜「上路五年」混淆施行期間與統計期間；刪統計支線。
- 判決確定的只有十二個，有罪五個、無罪七個。 → 刪除。｜不再展開判決統計，保留單一機制。
- 有罪的平均關三到六個月。 → 刪除。｜「平均」與區間混用，且偏離核心機制。
- 最有意思的，是羅大佑被中國禁唱的那首歌。 → 刪除。｜刪評語與歌曲支線。
- 行政院發言人拿它回嗆，說台灣可以傳唱。 → 刪除。｜歌曲回嗆無助於交代本片法律要件。
- 同一首歌，一邊禁、一邊唱，界線就畫在這裡。 → 刪除。｜兩岸歌曲處境不能直接定義法律界線。
- 這條線管的是錢跟指示，不管你罵得多兇。 → 不管你批評誰，反滲透法都得查有沒有受滲透來源指使。／還得查，有沒有做法條禁止的事。｜刪過度免責保證，限定反滲透法，補行為要件。
- 台灣的言論空間能守住，靠的就是有人在乎這條線。 → 羅大佑能上節目罵總統，因為批評總統本身不構成這些違法行為。｜刪格言，回答鉤子；限定前文要件，不替所有辱罵保證免責。

## 仍有事實風險的句子

- 「他在廣播專訪裡，罵總統跟行政院長『狼狽為奸』。」依事實第 2 條，仍是媒體整理轉述，本次未取得原始音檔。
- 「梁文傑回他，台灣沒言論自由，他怎麼上得了節目？」依第 4 條作間接轉述，不能倒推成羅大佑親口說過「台灣沒有言論自由」。
- 「刑法一百條把強暴、脅迫寫進要件，也處罰預備犯。」依第 14 條，沒有展開特定意圖要件，不宜單獨剪成內亂罪的完整定義。
- 「羅大佑能上節目罵總統，因為批評總統本身不構成這些違法行為。」這是依前文要件作的解釋，並非司法對本次發言的裁判，也不代表所有辱罵都不受其他法律規範。
