## 初稿（2026-11-02 夜間批次）照 genie-humanizer 逐句念過。初稿 → 定稿：

- 台北這麼老，為什麼用到長照的人這麼少？ → 台北長輩比例這麼高，為什麼用到長照的人這麼少？（「台北這麼老」是翻譯腔，城市不會老；全片統一叫「長輩」，寫出是比例高）
- 因為長照給的時間，比長輩要人顧的時間少太多。 → 因為長照給的時間，比需要人顧的時間少太多。（「長輩要人顧」念起來像長輩在要求；主詞前一句已經講過）
- 晚上更難，因為台灣上夜班的居服員非常少。 → 晚上更難，台灣上夜班的居服員很少。（「非常」念起來像公文；壓字數）
- 所以很多台北家庭，乾脆請外籍看護住在家裡。 → 所以很多台北家庭，乾脆請外籍看護住家裡。（口語省「在」）
- 但日本十幾年前，就開始補晚上這一段。／二〇一二年起，日本居服員日夜定時上門，半夜按鈴也有人來。 → 但日本從二〇一二年起，就開始補晚上這一段。／居服員白天晚上都定時上門，半夜按鈴也有人來。（「十幾年前」跟「二〇一二年」講兩次同一件事，合成一次；「日夜」是書面語，改「白天晚上」）
- 這種據點，六年從一百七十六個變九百四十六個。 → 這種服務的據點，六年從一百七十六個變九百四十六個。（「這種據點」指不清楚，寫出是哪種服務）
- 市府請市立聯合醫院帶頭加開。 → 市府請聯合醫院帶頭加開。（「市立」多餘，台北人都叫聯合醫院）
- 平均等床，三年內從六十四天縮到十九天。 → 平均等一張床，三年內從六十四天縮到十九天。（「等床」太縮，念起來不像人話）
- 引進按鐘點計費的移工，晚上來幫忙。 → 引進按小時請的移工，補晚上的照顧。（「按鐘點計費」是書面語；「晚上來幫忙」沒講幫什麼，跟上一句「補晚上的人力」接起來）
- 移工要先受訓兩年，法規也要先改。 → 移工要先受訓兩年，法規也得跟著改。（一句兩個「先」，聽起來在排順序）
- 長輩要的是整天有人在，不是一天三小時。 → 長照現在只補上一天裡的三小時。（「不是 X，是 Y」二元對比加格言收尾，改成回扣鉤子的具體數字）
- 剩下的時間，多半是家人跟外籍看護在扛。 → 其他二十一小時，多半是家人跟外籍看護在扛。（「剩下的時間」改成機制段講過的二十一小時，同一個東西同一個叫法）

其餘句子念過不用改：鉤子第三句、機制第一、二、五句、「回到台北，有兩種主張。」、兩個「第一種／第二種」起頭、兩個「代價是…」、衛生局那句、都更那句、提問句。
