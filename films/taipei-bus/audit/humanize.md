## 初稿（2026-11-01 夜間批次）照 genie-humanizer 逐句念過。初稿 → 定稿：

- 因為開公車的人不夠了。 → 因為公車司機不夠。（「開公車的人」跟後面的「司機」是同一群人，統一叫「公車司機／司機」；「了」多餘）
- 台北公車司機三千七百多個，還缺五百多個。 → 二〇二五年，台北有三千七百多個公車司機，／還缺五百多個。（補年份，限定範圍寫進事實；「有」字讓句子能念）
- 業者只好減班。 → 司機少，公車公司只好減班。（「業者」是新聞稿用語；首爾段也講公車公司，同一個東西同一個叫法）
- 台北兩百八十八條公車路線，三年內有一百四十七條改過班表或路線。 → 二〇二三年到現在，台北超過一半的公車路線改過。（兩個數字擠一句，念不完；「三年內」跟原文 112–115 年對不上，寫起訖年；147/288 改成「超過一半」）
- 班表排得緊，開車就急，乘客抱怨也多。 → 班表排得緊，車就開得急。／乘客抱怨跟著變多。（一句三件事，拆開）
- 抱怨一多，更沒人想開公車。 → 壓力一大，更少人想來開公車。 → 壓力大，更少人想開公車。（「更沒人」是誇張，改「更少人」；壓縮字數）
- 首爾也碰過一樣的事。／二〇〇四年以前，公車公司搶客人，司機一路狂飆。 → 二〇〇四年以前，首爾的公車公司搶客人。／司機一路狂飆。（開場句沒資訊，刪；一句兩件事拆開；第二版「也在搶客人」的「也」暗指台北公車公司在搶客人，原文沒這說法，刪掉）
- 後來市政府把票錢收在一起，虧的錢由市政府補。 → 後來，首爾市政府把票錢收在一起。／虧的錢，由市政府補。（拆兩句；「首爾市政府」寫全名，「市府」只指台北市府）
- 司機不用再搶客人，薪水也調高。 → 司機不用再搶客人。／薪水也調高了。（一句一件事）
- 改完隔年，公車事故少了百分之二十四。 → 改完隔年，公車事故少了兩成四。（比例統一用「成」念，不跟「百分之」混講）
- 公車平均快了三成。 → 刪除（壓字數到 380；留事故跟搭乘人數兩個結果）
- 搭公車的人多了百分之九點四以上。 → 搭公車的人，多了將近一成。（小數點念出來聽不清楚，改成「成」）
- 第一種，加薪留人，再找機器幫忙。 → 第一種，先加薪，再試無人公車。（「找機器幫忙」是比喻，換成真名「無人公車」，後面都叫這個）
- 市府要業者幫司機加薪八千元。 → 二〇二五年起，市府要公車公司幫司機加薪八千。（補年份；業者 → 公車公司）
- 接著在十五條公車專用道，推動無人自駕公車。 → 無人公車先在十五條專用道試跑。（「推動」是公文用語；「無人自駕公車」跟「無人公車」兩個叫法，統一；主詞寫出來，避免聽成加薪的公車公司去試跑）
- 無人自駕公車最快二〇二七年下半年才上路測試。 → 最快二〇二七年下半年才上路。（主詞上一句剛講過；「試跑」「測試」重複）
- 第二種，改善司機的工作條件。 → 第二種，市府直接補貼司機薪水。（「改善工作條件」是空泛動詞，換成實際做法）
- 在重要折返點設置駕駛長休息站。 → 在折返點，蓋司機休息站。（「設置」「駕駛長」是公文腔；同一群人叫「司機」）
- 再照每站每小時的載客量，分區重整路網。 → 再照每站的載客量重排路線。（「分區重整路網」是政策用語）
- 代價是錢，薪水補貼市府每年都要編預算。 → 代價是錢。／這筆補貼，市府每年都要付。（拆句；「編預算」改口語「付」）
- 台北公車一天載一百一十四萬人次，每一班車都要有一個司機來開。 → 台北公車一天載一百多萬人次。／每一班，都要有司機來開。（拆句；壓字數）
- 你最久等過一班公車多久？ → 你等公車，最久等過多久？（原句兩個「多久／最久」糾在一起，念起來繞）
- 其餘句（鉤子問句、沒減的班司機就得趕、回到台北有兩種主張、代價是時間、代價是錢、收尾兩句）念過無需改。
