### 1. 你看懂的內容

這支片說，民主社會看起來很吵，部分原因是少數人發言特別多，對立內容又容易被傳播。公開爭論是民主運作的一部分，安靜也不代表大家意見一致。片尾希望觀眾別把網路聲量當成整個社會，投票時多想共同生活的家鄉。

### 2. 一句話主旨

民主社會看起來的分裂，可能被少數人的聲量、平台傳播和彼此的誤解放大。

### 3. 前 3 秒

可能讓關心政治、厭倦爭吵的人停下來。「民主國家怎麼總是這麼亂」容易理解，也有情緒共鳴。

但第一段的「亂」可能指爭吵、政治失能或社會動盪，後文主要談網路聲量與認知落差。第三句承諾「亂可能比較小」，範圍比後面的證據大。

### 4. 逐句追問

以下只列讀到時有疑問的句子；其餘句子能直接理解。

- 第 1、3 句：「亂」指什麼？「小」指參與爭吵的人少，還是實際分歧小？
- 第 4、5 句：分析哪一年？「百分之十的人」是哪一群人的百分之十？是美國推特使用者，還是有發政治推文的人？
- 第 6 句：前句算的是推文數量，這裡的「聲音」是否也只指發文量？發得多，不一定代表被更多人看見。
- 第 7、9 句：「講對面陣營」就等於「吵架」嗎？這個研究如何支持前一句？
- 第 8、9 句：分析哪些平台、哪段期間？「兩倍」比較的是每則貼文平均分享次數，還是全部分享總數？
- 第 10 句：「一個怒算五個讚」是排序權重嗎？適用什麼時期？這和吵架內容被轉傳之間，還缺一層說明。
- 第 11、12 句：公開表達不同意見，和前面說的吵架，是同一件事嗎？「公開比」是在比什麼？
- 第 13 句：沒看上一集的人，是否只能直接接受「覺得自己是少數就常常不講」這個前提？
- 第 16、17 句：「極端」怎麼定義？「實際」如何測量？「將近一倍」是相對比例，還是百分點？
- 第 18 句：前面談的是「極端者有多少」，這裡怎麼變成對面整體「有多極端」？
- 第 20、21 句：社會真有分裂、少數人又特別大聲，不能同時發生嗎？
- 第 22 句：哪一年、哪裡的投票？從美國研究轉到這場選舉，中間有什麼依據？

### 5. 問題清單

- [硬傷] 第1句：「亂」的範圍大於後文證據，可能被理解成政治失能或社會動盪 → 改成「民主國家怎麼好像總是在吵架？」
- [硬傷] 第3句：「亂比較小」混淆發言人數、分歧程度與實際衝突 → 改成「但我們聽見的爭吵，可能不代表整個社會。」
- [小問題] 第4句：「一年」沒有交代年份 → 補上研究分析的年份。
- [硬傷] 第5句：「百分之十的人」缺少母體，無法理解比例 → 明確寫出是哪群人的百分之十。
- [小問題] 第6句：「聲音」可能讓人把發文量理解成觸及或影響力 → 改成「這些政治推文，大多由一小群人發出。」
- [硬傷] 第7句：後文的「提到對面陣營」不足以直接支持「吵架容易被轉傳」 → 將本句限縮為後文實際比較的貼文類型。
- [小問題] 第8句：未交代分析平台與期間，讀者難以判斷適用範圍 → 補上平台與研究期間。
- [硬傷] 第9句：「兩倍」缺少計算單位 → 說清楚比較的是每則平均分享次數，還是分享總數。
- [硬傷] 第10句：「一個怒算五個讚」可能被誤解成互動次數或直接增加五倍曝光 → 明說這是排序權重，並交代適用時期。
- [小問題] 第11句：從網路吵架轉成民主運作，可能把敵意與意見交鋒混在一起 → 改成「民主本來就會讓不同意見公開交鋒。」
- [小問題] 第12句：「公開比」意思不完整 → 改成「公開表達、辯論的地方」。
- [小問題] 第13句：引用上一集，讓獨立觀看者缺少支撐這個前提的說明 → 移除「上一集說過」，在本集補一句必要解釋。
- [硬傷] 第16句：「極端」沒有定義，調查也缺少可辨識名稱 → 補上調查名稱，說明判定極端的標準。
- [硬傷] 第17句：「實際」的測量方式與「將近一倍」的算法不明 → 交代實際比例如何取得，並直接列出猜測值與測得值。
- [硬傷] 第18句：把極端者「人數占比」推成對面整體的「極端程度」 → 改成「我們以為對面有更多人立場極端。」
- [硬傷] 第21句：把真實分裂與聲量放大寫成二選一，兩者可能同時存在 → 改成「我們聽見的聲音，有多少代表真實分歧，又有多少被少數人的聲量放大？」
- [硬傷] 第22句：投票日期缺少年份、地點，也沒有交代美國研究與這場選舉的關係 → 補明選舉資訊，並限縮前述研究對本地情況的推論。
- [小問題] 第22句：「我們在乎的是同一個家鄉」替所有觀眾斷言動機 → 改成邀請語氣，例如「投票時，也想想我們希望家鄉變成什麼樣子。」
