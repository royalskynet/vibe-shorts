# scam-map 旁白稿與數據來源（待稽核）

核心結論＝旁白稿逐句陳述的事實。下方「旁白稿」是要對外發布的文字，「數據來源」是作者自述的出處與算法。

## 旁白稿
### 鉤子
照人口算，電話網路詐騙最多的城市，你猜是哪裡？
### 錨點
去年全台的電話網路詐騙，警方受理十五萬六千件。平均每一百四十九個人，就有一件。
### 揭曉
答案是新竹市。每一百一十四個人就有一件，比全國平均多三成。
過去二十一個月，新竹市有十八個月排第一。
最少的是金門，只有新竹的四分之一。
### 轉折
新竹有科學園區，會不會是騙子專挑工程師？
數字看不出來。新竹人被騙的方式，比例跟全台灣幾乎一樣。
最多的一種是假網拍，兩邊都佔兩成多。
### 落點
騙走最多錢的是假投資，佔了一半。
最常見的，卻是你每天都在用的網購。
### 提問
你上次網購，有先查過賣家嗎？

- API 根網址 `https://165dashboard.tw/CIB_DWS_API/api/Dashboard/`，免登入。`date` 是台灣當月 1 日 00:00 換成 UTC（前一天 16:00Z）。
- 手法只取每月前五名加總，其餘歸 `Other`。佔比是下限估計。
- `Losses` 的單位未確認，所以稿裡不寫金額，只寫佔比。

### 口徑（反方稽核 2026-10-14 後補）

- `Cases` 是「詐欺犯罪受理件數」，不是被害人數；同一人可能多次報案。稿裡一律寫「每幾人一件」，不寫「幾人有一人被騙」。依據：警政署統計室「113年9月至12月『165打詐儀錶板』詐欺犯罪受理件數…」 https://www.npa.gov.tw/ch/app/data/view?id=2206&module=wg054&serno=7218ce42-167b-489b-817b-71fcce2af534
- 156,411 有第三方彙整標為「電信網路詐騙整體」，同年全類別 176,242 件（https://fromnineon.com/data/taiwan-fraud-statistics/ ，2026-10-08 更新）。儀錶板縣市資料只涵蓋電信網路類（同頁：「縣市資料只涵蓋電信網路類詐騙」），所以鉤子與錨點都限定「電話網路詐騙」，排名是這一類的每人口受理件數，不是所有詐騙。
- 手法比例相近只說明全市分布，推不出「詐團沒有鎖定工程師」；TVBS 2025-03-08 報導新竹市工程師是詐團目標（https://news.tvbs.com.tw/local/2801542）。稿裡寫「數字看不出來」，不寫否定。
